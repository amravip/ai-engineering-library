<div class="intro">

The AI Engineering Library is a series of twelve books for software developers who want to build AI features they can explain and trust. Each book follows one realistic project, such as a pizza shop's assistant or a banking support assistant, and adds one idea at a time to the same code.

</div>

<ul class="value-points">
  <li><strong>Local first.</strong> The examples run on your own computer through Ollama. There is no account and no paid API. Hosted providers are optional, and no core exercise needs one.</li>
  <li><strong>One real project per book.</strong> You start from the simplest working version and move towards a production-aware one.</li>
  <li><strong>Self-contained books.</strong> Each book prints the code, setup commands, data and expected output that its exercises need.</li>
</ul>

## Where to start

If you are new to AI engineering, start with **Applied AI Engineering**, the entry point of the series. The list below follows volume order, but you do not have to read it in sequence. Each book stands on its own, so you can go straight to the one that covers the topic you need, such as retrieval, agents or security.
