## Requirements

You need a computer that runs Python and Ollama. The book's code uses only the Python standard library, so there are no packages to install for the examples. The tests need pytest.

- **Python 3.10 or newer.** The book uses Python 3.13.
- **Ollama**, the local model runtime, running on your computer.
- **`qwen3:8b`**, the default chat model. It is about 5.2 GB and runs on a laptop with 16 GB of memory.
- **`qwen3:1.7b`**, an optional smaller chat model, about 1.4 GB, for a computer with 8 GB of memory. Every example still runs with it.
- **`nomic-embed-text`**, the embedding model used from Chapter 3 onward, about 274 MB.
- **pytest**, for the tests only.

Setting up these tools is covered in [Running the examples](/running-the-examples/) and in the Setup and Reproducibility appendix of the book.
